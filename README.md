# OPV — парсер кредитных отчётов

Серверный парсер ПКБ/ГКБ и пенсионных выписок (FastAPI).

- Vercel: проект `opv`, Root Directory `server`, production branch `main`.
- API: `POST /parse`, `GET /health`.
- Поле `pension_orgs` принимает номера организаций или БИН через запятую; пустое значение учитывает все организации.
- Возвраты исключаются из СРЗП. Временные PDF удаляются при успехе и ошибке.
- Excel сохраняет листы «Анкета», «Кредиты», «Анализ».

Секрет `APPS_SCRIPT_URL` задаётся в настройках Vercel. `DEV_ALLOW` предназначен только для локальной разработки.

Веб-хаб Apps Script и его приватная конфигурация остаются отдельно от открытого репозитория. Его изменения нужно публиковать в Apps Script отдельно.

## Проверка

Установить зависимости из `server/requirements.txt`, дополнительно `reportlab` и `httpx`; нужен шрифт DejaVu Sans. Запуск: `python -m unittest discover -s server/tests -v`.

Проверены 7 сценариев, включая синтетические PDF, ЭЦП-контейнер, Excel, HTTP multipart, выбор организаций, возвраты и ошибки. Проверка криптографической подписи ЭЦП не выполняется. OCR на Vercel не включён.

Изменения в `main` автоматически запускают деплой существующего проекта OPV.
