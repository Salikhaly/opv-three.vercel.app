# OPV — парсер кредитных отчётов

Python API: `server/` (FastAPI). Основной веб-хаб: `Index.html` (Apps Script). Статическая страница: `site/`.

Vercel project: `opv`, Root Directory: `server`, production branch: `main`.

Изменения API публикуются через GitHub → Vercel. Изменения Apps Script публикуются отдельно в существующем Apps Script.

Подробности внедрения и проверки: `CHANGES.md`.

Конфигурация и секреты находятся вне репозитория.
